# Base de Conhecimento - AlertaSUS 2.0

## Sobre o AlertaSUS
O AlertaSUS é um serviço independente que monitora regulações de saúde (consultas e exames) no SUS de Teresina-PI.

## Cadastro de Regulação
O usuário deve usar o comando /cadastrar_nova. O passo a passo é:
1. Digite /cadastrar_nova.
2. Informe o número do Cartão SUS (15 dígitos).
3. Informe o nome completo do paciente.
4. Informe o celular com DDD.
5. Informe a data de nascimento (DD/MM/AAAA).
6. Informe o ID da Regulação.
7. Informe o CBO/Especialidade.
8. Informe o Procedimento (Exame ou Consulta).
9. Aceite o Termo de Consentimento LGPD.
**Não é necessário anexar documentos (CPF, RG).**

## Verificar Status da Regulação
Após cadastrar, o usuário deve acessar o menu e escolher:
- /verificar_especifico - Para verificar uma regulação específica.
- /verificar_todas - Para verificar todas as regulações cadastradas.

## Planos e Assinaturas
- **Degustação (Grátis):** Validade de 7 dias. Após esse período, é necessário contratar um plano Pro.
- **Trimestral:** R$ 9,99 (3 meses, até 5 regulações).
- **Semestral:** R$ 14,99 (6 meses, até 9 regulações).
- Pagamento via Pix (QR Code ou Copia e Cola). Acesso liberado após confirmação.

## Comandos Principais
- /iniciar - Menu principal.
- /cadastrar_nova - Cadastrar regulação.
- /verificar_todos - Verificar todas as regulações.
- /verificar_especifico - Verificar uma regulação.
- /planos - Ver planos.
- /corrigir - Corrigir dados.
- /excluir - Excluir regulação.

## Atendimento

## Perguntas Frequentes (FAQ)
1. Como cadastrar? Use /cadastrar_nova.
2. Como verificar status? Use /verificar_especifico ou /verificar_todas.
3. Como pagar? Via Pix, acessando /planos.
4. Preciso de documentos? Não.
5. O AlertaSUS é oficial? Não, é independente.
